# 하루의 음악 — GitHub Pages용

전시회, 미술수업, 공방, 카페 등에서 사용할 수 있는 200곡 오리지널 랜덤 음악 플레이어입니다.

## GitHub Pages 올리는 방법

1. GitHub에서 새 Repository를 만듭니다.
2. 이 ZIP의 압축을 풉니다.
3. `index.html`, `manifest.json`, `sw.js`, `icon-192.png`, `icon-512.png` 다섯 파일을 Repository 최상위에 업로드합니다.
4. Repository의 **Settings → Pages**로 이동합니다.
5. **Build and deployment → Source**를 `Deploy from a branch`로 선택합니다.
6. Branch는 `main`, Folder는 `/ (root)`를 선택하고 Save를 누릅니다.
7. 잠시 후 표시되는 GitHub Pages 주소로 접속합니다.

## iPhone에서 앱처럼 사용

GitHub Pages 주소를 Safari에서 엽니다.

Safari 공유 버튼 → **홈 화면에 추가**

이후 홈 화면 아이콘을 누르면 앱처럼 실행할 수 있습니다.

## 중요

iPhone/Safari의 보안 정책 때문에 첫 재생은 반드시 사용자가 `오디오 시작` 버튼을 직접 눌러야 합니다.
